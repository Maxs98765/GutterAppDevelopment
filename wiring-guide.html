Wiring guide -- Arduino-free build

Matches BOM.xlsx exactly: Arducam IMX708 CSI camera, Cytron MD13S motor driver, BRINGSMART 12V worm-gear motor, solar-charged 12V battery system. No Arduino Uno, no L298N, no USB camera anywhere in this build.

12V power logic signal (PWM / DIR) ground / motor leads / CSI ribbon wireless (WiFi)
Pin numbers below are confirmed against Waveshare's own pinout diagram for the ESP32-P4-WIFI6-DEV-KIT (its "Pinout Definition" header table), not guessed. An earlier draft of this project had the motor on GPIO40/GPIO41, which that diagram shows are not on the 40-pin header at all -- they're used internally for the onboard microSD card slot. Fixed to GPIO4/GPIO5, which the same diagram confirms are plain, unused header pins. If you're building this on a different P4 board, re-check its own pinout diagram before trusting these four numbers, and update main/config.h to match if they differ -- the firmware reads every pin number from that one file.

Enclosure and finishing parts

The remaining BOM items are assembly/finishing, not wiring per se: a project box (weatherproof enclosure for the electronics), a cable gland kit (weatherproof cable entry into that box), wire loom (bundles/protects runs between the box and the motor/camera), cable anchors and gorilla/foam tape (securing wiring and the panel), a ferrule crimping kit (clean, secure terminations into the bus bar and driver terminals -- strongly recommended over bare stranded wire in screw terminals), and lever (Wago-style) connectors for quick, tool-free splices where a permanent crimp isn't needed.

Matches the parts list in BOM.xlsx and the pin assignments in main/config.h. If you change a pin in config.h, update this diagram's connection table to match, or it will fall out of sync with the firmware it's supposed to describe.
